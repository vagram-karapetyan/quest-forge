      ❓ Builder Guide (Twine-level)
      • 2D Map: switch to “Graph Map (2D)” in the top bar to view scene cards and directional links. Drag nodes freely with your mouse!
      • Variables: define initial values in Quest Settings (e.g. {"gold": 0, "hp": 100}). Use {gold} in scene text or choices.
      • Conditions & Actions: choices can mutate variables (add, set) and check item/variable conditions.
      • Media & Markdown: supports bold, italic, blockquotes, lists, plus scene illustration and ambient audio URLs.
      • Duplication: clone entire quests or individual scenes with all transitions in one click.
      • HTML Export: compiles the quest into a single self-contained offline HTML file!
